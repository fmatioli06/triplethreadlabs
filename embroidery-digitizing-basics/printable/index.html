DESIGN PRE-FLIGHT CHECK

Five minutes before the real garment, on every new file, in order. Read the test stitch before the customer piece goes on the machine.
A stitch file is instructions, not a picture. Test the instructions before the garment pays for them.

THE FIVE CHECKS

  1. Confirm what arrived. The format your machine reads, the finished size you ordered, the stitch count in hand. Missing run sheet: ask now, not mid-run.
  2. Measure the smallest lettering. About 5 mm tall for plain block is the starting point, more for script and serif. Under the floor, the fix belongs in the file.
  3. Find the crowded places. Tiny detail, stacked color changes, one area doing heavy work. That is where breaks and blobs are born.
  4. Test stitch the actual file. Scrap close to the real fabric, the backing you plan to use. Not a trusted design, this design.
  5. Write down what you ran. File name and version, size, fabric, backing, what the test showed. The reorder starts from your notes.

READ THE TEST STITCH

  • Fails in the same spot twice: it lives in the file. Photo it and send it back with the facts.
  • Problems wander around: it lives in your setup. Backing, hooping, needle, path.
  • Lettering filled in: too small for the fabric, or shrunk there. Bigger, bolder, or dropped.
  • Gaps along the edges: the pull conversation. Name pull compensation when you write.

ORDERING: WHAT TO SEND

  • The cleanest artwork you have, vector if it exists.
  • The finished size it will sew at, exact, not "about left chest."
  • The fabric or item, and where it will sit on it.
  • Your machine format, your colors, your deadline.

ORDERING: WHAT TO ASK

  • What will I receive? Machine format, size, stitch count, run sheet with the color order.
  • What size was it digitized for? A second size usually means a new file. Know before the reorder.
  • How do revisions work? Send a photo and three facts: fabric, size, what you saw.

WORDS THAT MATTER

  • Density: how tight the stitches pack. Too much hammers one spot, too little shows fabric.
  • Pull compensation: width added back because stitches pull in. Too little opens gaps.
  • Underlay: the foundation under the visible stitches. Thin underlay, tired design.
  • Working file: the editable source. Real resizing and edits happen there, not on the machine file.
Resizing is not free, small nudges only. Same spot twice means the file. Wandering means your setup.
