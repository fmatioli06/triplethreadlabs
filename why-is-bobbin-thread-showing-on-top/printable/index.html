BOBBIN SHOWING CHECK ORDER

Bobbin thread on top means the top thread is winning the pull. Read the pattern, clean the bobbin side, rethread, test on scrap. Tension is last.
Read the pattern. Bobbin side first. Rethread. Tension last.

READ WHERE IT SHOWS

  • Everywhere: shared setup. Bobbin side or top path as a whole.
  • One color or section only: that spool, that path, or that dense section.
  • Satin only: satin pulls harder and shows a small imbalance first.

THE TEST THAT TELLS THE TRUTH

  • Stitch a short satin column on scrap in the same fabric family as the job.
  • Flip it over. Bobbin thread should sit down the middle of the back.
  • Keep the scrap. One change, one test, read the back each time.

CHECK 1: BOBBIN SIDE FIRST

  • Clean the bobbin area and case before any setting changes.
  • Route the bobbin thread per your manual, under its spring or guide point.
  • Bobbin seated fully, turning the right way, wound evenly.
  • Case check: nicks or rough spots while it is out.

CHECK 2: TOP THREAD PATH

  • Rethread the whole path from the spool, every guide in order.
  • Clear snags: spool edge, uneven feed, thread wrapped where it should not be.
  • One color only: swap that spool or move it to another needle path.

CHECK 3 AND 4: NEEDLE, DESIGN

  • Fresh needle. A dull or bent needle drags and changes the pull.
  • Problem started after a change: swap that one part back and retest.
  • Dense satin or packed lettering pulls harder. Test a known good design on the same scrap.

CHECK 5: TENSION LAST

  • Only if it shows everywhere after checks 1 to 4.
  • Note your starting setting before you move anything.
  • One small step, one satin test, read the back. Repeat only if needed.
  • Bad ever since a service, tension already turned both ways: technician, not another guess.
Everywhere means shared setup. One color means that spool, path, or section. One change, one test.
