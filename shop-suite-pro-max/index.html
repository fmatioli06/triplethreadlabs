Straight answers

How is this different from Shop Suite Pro?
Max adds five modules on top of Shop Suite Pro: the Patch Price Builder, the HTV Vinyl Calculator, a rebuilt Profit and Expenses, Shopify Export, and the Shop Policy Builder. It also adds stitch file reading inside the Embroidery Calculator. If you already run your shop on Pro, your saved data carries over in the same browser.
Will it work on my computer?
Any Windows or Mac desktop or laptop. Open the file in Chrome, Edge, Safari, or Firefox. No install, no login, no internet needed after download.
Does it work on my phone or tablet?
No. Shop Suite Pro Max is built for desktop use only — it's not optimized for small screens and won't work well on a phone or tablet.
Does my data save automatically?
Yes. It saves automatically in the browser you use it on. To work on a second computer, use Export Backup in Shop Setup and restore from that file on the other computer.
Does it read my stitch files?
Yes. In the Embroidery Calculator you can add a DST or PES file to any location, and it fills in the stitch count, color count, and design size from the file itself, so the price is built on the real design. JEF and EXP files are not read yet.
Can I quote embroidery and DTF on the same job?
Yes. The Quote Builder lets you add embroidery and DTF line items to the same customer quote and export the whole thing as a single PDF.
Is it a physical product? Is this a subscription?
Neither. It's an instant digital download, one HTML file. Nothing ships. $63.99 once, no renewal, no account, no expiry.
