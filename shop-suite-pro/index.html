Straight answers

How's this different from the Embroidery Pricing System?
The Embroidery Pricing System ($24.99) is focused on pricing — stitch count in, sell price out. Complete Embroidery & DTF Shop Manager adds the Quote Builder, Order Tracker, Inventory, Dashboard, DTF Calculator, and Shop Setup on top of that. If you only need to price jobs, the standalone is the right tool. If you want to run the whole shop from one place, this is built for that.
Will it work on my computer?
Any Windows or Mac desktop or laptop. Open the file in Chrome, Edge, Safari, or Firefox. No install, no login, no internet needed after download.
Does it work on my phone or tablet?
No. Complete Embroidery & DTF Shop Manager is built for desktop use only — it's not optimized for small screens and won't work well on a phone or tablet.
Does my data save automatically?
Yes. It saves automatically in the browser you use it in. It doesn't sync between devices — use the Export Backup option in the tool to keep a copy or move your data to a different computer.
Which version should I use — US or European?
Use the US version if your shop prices in dollars, inches, and standard DTF sheet or gang sheet sizes. Use the European version if your shop prices in euros, centimeters, DTF roll meters, or stabilizer rolls. Both are included in your download.
Can I quote embroidery and DTF on the same job?
Yes. The Quote Builder lets you add embroidery and DTF line items to the same customer quote and export the whole thing as a single PDF.
Is it a physical product? Is this a subscription?
Neither. It's an instant digital download — the US and European HTML versions plus a setup guide PDF. Nothing ships. $51.99 once, no renewal, no account, no expiry.
